
# Data Analyst Internship - Medical Appointment No-Shows Task

## 📌 Project Overview
This project focuses on data cleaning, preprocessing, and predictive modeling using the **Medical Appointment No-Shows** dataset to predict patient attendance patterns.

## 🛠️ Tools & Technologies Used
* Python (Pandas, NumPy, Scikit-Learn)
* Matplotlib & Seaborn
* Google Colab & GitHub

## 📈 Model Performance & Key Insights
* **Model Used:** Random Forest Classifier (with balanced class weights)
* **ROC-AUC Score:** 0.6964
* **Key Insights:** Feature importance analysis identified **WaitingDays** and **Age** as the primary drivers influencing appointment no-shows.
